# 🎙️ Speech File to Text in Python

A simple Python project by [@MrXMART-Abhyuday](https://github.com/MrXMART-Abhyuday) that converts your **spoken words into text** using your computer’s microphone.

## Features
- Captures voice input from your microphone in real time
- Converts speech to text using Google’s free Speech Recognition API
- Automatically adjusts for background noise
- Compatible with built-in and external microphones

## Installation

```bash
git clone https://github.com/MrXMART-Abhyuday/speech-file_to_text_python.git
cd speech-file_to_text_python
pip install -r requirements.txt
